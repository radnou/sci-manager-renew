B — Modal Élargi (2 colonnes)

~560px de large. Header avec titre + contexte (nom du bien). Body en grille 2 colonnes pour les champs date/montant. Champ locataire en tag chips avec ajout. Pour les formulaires plus longs (bail: 7 champs, associé: 4 champs).

Proposition

Utiliser les deux tailles selon le formulaire :

  • Compact (A) → Loyer (3 champs), Charge (3), PNO (4), Frais agence (3), Inviter associé (3)
  • Élargi (B) → Bail (7 champs + locataires), Créer SCI (4+), Ajouter bien (5+)

Cliquez sur le layout qui vous plaît, ou validez la proposition "les deux" dans le terminal.
